Why I built this

When I started learning to code, I'd Google a simple question and end up on a Stack Overflow thread from 2013 with 47 conflicting answers and code I didn't understand.

I wanted something that would just talk to me like a human and explain things at my level — without assuming I already knew half the stuff. So I built it.

This is also my first real project using an external API, so there's probably stuff that could be done better. If you see something dumb, feel free to open an issue or PR on GitHub.
